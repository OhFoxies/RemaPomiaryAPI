# Python API for managing RemaPomiary licenses

This API will be used by website to purchase, activate and manage licenses for my Mobile Application RemaPomiary.
The RemaPomiary is an app which automates the process of doing obligatory electrical installation check every 5 years. 
The API uses FastAPI, SQLAlchemy 2.0 and PostgreSQL Database.
